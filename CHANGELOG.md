# Change Log

All notable changes to the "layout-lens" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.1] - 2025-10-05

- Added configuration option to toggle the visibility of the layout lens.
- Improved responsiveness of the layout
- Changed the icon
- Added keywords to package.json for better discoverability.
- Changed default visibility to false for shared properties.

## [0.0.1] - 2025-10-03

- First version of the extension, unreleased.
